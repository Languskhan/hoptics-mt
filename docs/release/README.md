# Release extras

Attached to every GitHub release by the build (`.github/workflows/build.yml`, "Attach to release"):

- `START-HERE-Hoptics-MT-install-guide.html`: the install and test guide.
- `Hoptics-MT-User-Guide-v*.pdf`: the user guide (the newest version is attached).
- `Hoptics-MT-T-Deck-Plus-M9-Guide-v*.pdf`: two pages on the T-Deck Plus and ThinkNode M9 (keys, the M9's
  Location card). Source: `guide-tdeck-m9-0.3.0.html` with `guide-img-030/`; print it from Chrome (Letter,
  background graphics on), or `google-chrome --headless --no-pdf-header-footer --print-to-pdf=... file.html`.

`guide-new-in-0.2.4.html` (with `guide-img/`) is the source of the guide's pages 16-17; print it from
Chrome (Letter, background graphics on) to rebuild them.
