Hoptics-MC

The Hoptics touch screens on MeshCore, companion role, for four boards. Works with the MeshCore apps. Live traffic, a map, chat with emoji, replies and message details, message sounds, stats, repeater management, themes and a lock screen, plus a web page on your Wi-Fi for sending messages, charts, line of sight and updates. Source and releases on GitHub.

Read first. This is a beta: please report problems (the radio can save a log for you under More → System). A first install erases the radio: its MeshCore identity (keys), contacts and channels are wiped, and it starts as a new node. If you want to keep an existing MeshCore identity, export its private key in the MeshCore app first. To go back, flash any firmware from flasher.meshcore.io. Already on Hoptics-MC? Choose Install and say no to erasing: that updates it and keeps everything.

Elecrow ThinkNode M7

observer + repeater · 0.3.4

No screen: it's run from a web dashboard. After installing, join the Wi-Fi network MeshCore-Setup-… from a phone and follow the setup page (name, radio, Wi-Fi or Ethernet, MQTT servers, admin password). Then open http://<node IP>/hoptics on your home network. Updates and role changes are done from the dashboard after that.

Elecrow ThinkNode M9

companion

Keys only: arrows move, OK opens, Back goes back. Message bubble: Chats. House: Home. Second bubble: the Public channel. Map: Nodes, with distances. GPS pin: send an advert (hold it to send one across the whole mesh).
